#  Hotel Booking Cancellation Analysis

##  Overview
Exploratory data analysis on hotel booking data to identify patterns and key factors influencing reservation cancellations across City and Resort hotels.

##  Analysis Covered
- Reservation status analysis (cancelled vs not cancelled)
- Comparison between City Hotel and Resort Hotel
- Pricing (ADR) impact on cancellations
- Time-series and seasonal trends (monthly patterns)
- Country-wise cancellation distribution
- Booking channel analysis (online, offline, groups)

##  Key Insights
- ~37% bookings are cancelled, impacting revenue
- Higher pricing (ADR) leads to higher cancellation rates
- January has highest cancellations; August has highest bookings
- Resort hotels are more price-sensitive
- Majority bookings come from online travel agents

##  Tools
Python, Pandas, Matplotlib, Seaborn
